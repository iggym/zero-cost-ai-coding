No tools published yet — this directory is waiting on its first build.

This page reads directly from data/metadata.json. Nothing is hardcoded, so the first entry that lands there is the first card that appears here. To add one:

  1. Run prompts/zero-cost-ai-coding-maestro.md against a research-and-build session, with SEARCH ON.
  2. Save the returned HTML file to tools/[slug].html.
  3. Append the returned metadata snippet to data/metadata.json.
  4. Save the research log to research-logs/[slug].md and link it — see docs/dual-value-plan.md §2.
  5. Run the pre-publish checklist (docs/dual-value-plan.md §7) before committing.

How a tool qualifies

01

The problem has to be real

Every research log cites evidence — a GitHub issue, an SO thread, or a paid competitor's existence — that someone actually hits this problem. No invented use cases.

02

The tool has to actually run

Browser-native, generated deploy-ready artifact, or a verified BYOK connector — every page ships a working tool, not a description of one.

03

The free claim has to be sourced

Every quota, rate limit, and reset cadence is checked against the provider's own current docs on a stated date, with the URL published in the footer.
