## 💡 THE NEED: ELIMINATING INFRASTRUCTURE TAX

Traditional modern web stacks incur heavy dependency bloat and recurring infrastructure costs:


```

❌ Traditional AI Stack:  React/Vite + Node Server + Managed DB + Paid LLM API == $50+/mo base cost before traffic.
✅ Zero-Cost AI Stack: Vanilla ES6+ Single-File + Cloudflare Pages + Supabase Free + Gemini/Groq == $0/mo perpetual runway.

```

> 💬 *"When your fixed costs are zero, you can experiment endlessly, launch dozens of micro-tools, and iterate without financial stress."* — [Explore the Hub](https://iggym.github.io/zero-cost-ai-coding)

### Core Operational Principles:
* 🆓 **Free-Tier AI Orchestration:** Combining Google Gemini API free tiers with Groq Llama endpoints for fast, zero-cost LLM inference.
* 🌐 **Zero-Build Architecture:** Eliminating `node_modules`, build steps, and bundling tools in favor of browser-native HTML, CSS, and ES6+.
* ⚡ **Serverless Edge Compute:** Running backend logic via Cloudflare Workers, KV, and Supabase Postgres without server management.
* 📱 **Terminal-Free Compatibility:** Building, testing, and deploying entirely via browser interfaces and light iPad/mobile workflows.

## 🛠️ QUICKSTART (LOCAL DEVELOPMENT)

No installation or build steps required. Run a local server directly:

```bash
# 1. Clone the repository
git clone [https://github.com/iggym/zero-cost-ai-coding.git](https://github.com/iggym/zero-cost-ai-coding.git)

# 2. Enter directory
cd zero-cost-ai-coding

# 3. Start a lightweight server
python3 -m http.server 8000

```

Open `http://localhost:8000` in your browser to access the interactive portal and guides! 🎈
