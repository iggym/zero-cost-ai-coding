Cron Expression Builder

Build a cron expression with live plain-English explanation and next-runs preview. Works for crontab, GitHub Actions, Airflow, Kubernetes CronJobs, and anything that takes standard 5-field POSIX cron.

limit: ∞ — pure client-side parsing, no network calls

What it replaces

Staring at * * * * * trying to remember which field is month vs. weekday, or pasting into crontab.guru to check if your expression actually does what you think it does.

    Works for: crontab, GitHub Actions (schedule.cron), Airflow, Kubernetes CronJobs, AWS EventBridge. GitHub Actions uses UTC for scheduled workflows — adjust your hour field if you want a specific local time.

    What breaks

    Only supports standard 5-field POSIX cron. 6-field (with seconds) or Quartz-style 7-field expressions won't parse. Next-runs preview caps at ~4 years of search; schedules that fire less often (e.g., Feb 29) may show fewer than 5 runs. Standard cron treats day-of-month and day-of-week as OR when both are specified — this tool treats them as AND, which matches what most people actually want and what GitHub Actions does.
