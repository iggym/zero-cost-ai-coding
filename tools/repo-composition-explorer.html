Why this exists

One endpoint, many blind spots

Source ↗

GitHub’s repository-languages endpoint returns byte counts by language. A quick visual view makes dependency, maintenance, and rewrite conversations less guessy.

Honest free limit

Public data, no key.

GitHub documents a primary limit of 60 unauthenticated REST requests per hour per originating IP address. This page makes one language request for each repository you inspect.

At the cap, GitHub returns a rate-limit response. Wait for the reset time shown by GitHub, or use fewer lookups. Private repositories are not available without authentication.
