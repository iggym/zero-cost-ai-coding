How to use it

  • Drop files, paste an image (Ctrl/⌘+V), or click the box to browse. Files are decoded locally.
  • Pick a format — Auto encodes WebP + JPEG (or WebP + PNG for transparent images) and keeps the smallest per image. Set quality and optional max dimensions.
  • Download files individually, grab everything as a .zip, or copy/download a JSON manifest of sizes.

What breaks

  • AVIF encoding isn't available in every browser; the option hides itself where unsupported.
  • The quality slider only affects lossy formats (JPEG/WebP/AVIF). PNG is lossless, so a PNG output can come out larger than an already-optimized PNG — for photos, use WebP or AVIF.
  • Canvas always strips EXIF/GPS/metadata (usually what you want — know it happens). Animated GIF/WebP/APNG become their first frame. HEIC/RAW won't decode in most browsers. SVG needs explicit width/height.
  • Browsers cap canvas around 16,384 px per side; larger images get scaled down. This is a re-encoder, not a lossless optimizer — it won't beat oxipng/pngquant on already-tiny PNGs, but it will take a 4 MB photo down to a few hundred KB.
