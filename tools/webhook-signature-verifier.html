Webhook Signature Verifier

Verify webhook signatures from GitHub (X-Hub-Signature-256), Stripe (Stripe-Signature), or any HMAC-SHA256 provider. Runs 100% in your browser using Web Crypto API — no API calls, no server, no limit.

What it replaces: Writing ad-hoc Node.js scripts with the crypto module, or paid webhook testing services. Hookdeck's webhook testing starts at $29/mo for 100k events; Svix charges from $49/mo for hosted signature verification. This does the same math in the browser tab you already have open.

How to use it

  1. Pick the webhook provider from the dropdown.
  2. Paste the raw request body exactly as your server received it (whitespace changes break signatures — don't reformat).
  3. Paste your webhook secret from the provider's dashboard (GitHub repo settings, Stripe endpoint "Reveal secret", etc.). The secret stays in memory and clears when you close this tab.
  4. Paste the signature value from the incoming HTTP header.
  5. Click Verify. The tool computes what the signature should be and compares it to what you received.
Free-tier limit: Unlimited. Web Crypto API is built into every modern browser (Chrome, Firefox, Safari, Edge). No provider account, no key, no quota.
