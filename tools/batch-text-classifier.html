Batch Text Classifier

Paste a list of items, define your labels, and classify each line using a real NLP model running entirely in your browser — no API key, no data leaves your machine. The model (67 MB) is cached after first load; subsequent visits load instantly. There is no rate limit because there is no server involved.

What it replaces

MonkeyLearn charges from $299/month for their paid text classification plans (the free plan caps at 500 queries/month). AWS Comprehend and Google Cloud NLP charge per-request for similar zero-shot classification. This tool does the same core task — sorting text into your custom categories — for $0, with your data staying on your device.

How to use

1. Paste your text: one item per line. Support tickets, user feedback, survey responses, log messages — anything you need sorted into buckets.

2. Define labels: comma-separated list of the categories you want. Could be "bug, feature, question", "urgent, normal, low", "positive, negative, neutral", or whatever fits your data.

3. Click Classify. The first run downloads the model (~67 MB). After that it's cached in your browser. Each line gets classified against your labels, with a confidence score.

What breaks

The model is trained primarily on English text. Non-English input will get unreliable results. Very short inputs (single words) may produce low-confidence classifications — the model works best with at least a full sentence of context. Classification runs on your CPU via WASM, so processing 100+ items on a phone may take a minute or two. WebGPU acceleration is available in the underlying library but isn't wired up here for cross-browser reliability — if you need that, you want a server-side pipeline instead.
