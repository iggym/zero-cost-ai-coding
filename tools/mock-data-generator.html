What it replaces

Mockaroo's free tier caps at 1,000 rows per download and requires an account for saved schemas (source: mockaroo.com). This tool has no row limit and no account requirement — everything runs in your browser tab.

How to use

  1. Add or remove columns, pick a data type for each
  2. Set how many rows you want (1–50,000)
  3. Pick a format: JSON, CSV, or SQL INSERT statements
  4. Click Generate, then copy or download the result

What breaks

Row counts above 10,000 may slow your browser while rendering output. Generated data uses Math.random() — pseudo-random, not cryptographically secure; don't use it for real secrets or tokens. Credit card numbers are random 16-digit strings, not Luhn-validated. Data is US-centric (names, cities, states, phone format).
