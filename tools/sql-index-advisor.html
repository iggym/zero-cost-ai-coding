📚 The ESR Composite Index Rule

To make multi-column B-Tree indexes efficient:

  • E (Equality): Columns tested with = or IS NULL come FIRST.
  • S (Sort): Columns in ORDER BY come SECOND to eliminate disk filesorts.
  • R (Range): Inequality columns (>, BETWEEN, LIKE 'abc%') come LAST.

⚠ What Breaks & Honest Limits

This tool runs static AST heuristics on query syntax. It cannot inspect live table row counts, data distribution statistics (pg_statistic), or index cache residency.

Always verify runtime execution timings with EXPLAIN (ANALYZE, BUFFERS) on realistic staging data before pushing migrations to production.
