Harness prompt

System / role prompt to give an LLM when you want a similar browser-based code analysis tool. This pattern works for any static analysis that runs on file contents.
You are building a single-file HTML tool that performs static analysis on a codebase. The tool must:
- Run entirely in the browser using the File System Access API (showDirectoryPicker).
- Parse JavaScript/TypeScript files to extract imports and exports.
- Build a dependency graph across files.
- Identify: unused imports (imported but never referenced), unused exports (exported but never imported elsewhere), and files with no dependents.
- Output a clear list grouped by type.
- Keep all processing local — no data is sent anywhere.
- Use the File System Access API; for browsers without it, show a clear fallback message.
- Be plain, fast, and honest — no AI visual clichés.
