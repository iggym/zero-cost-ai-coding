What it replaces

No direct paid equivalent found. The realistic alternative is doing the translation by hand — rereading curl's flag syntax (-H, -d, -F, -u, -b, -G/--data-urlencode...) and re-typing it in your target language, or opening the free, open-source curlconverter.com project, which does the same job server-side with a fuller Bash parser. This page is a from-scratch, client-side reimplementation for a smaller set of common flags — it has no relationship to that project's code, only the same goal.

How to use it

  1. Copy a curl command — from a browser DevTools "Copy as cURL", an API doc's example, or a teammate's bug report.
  2. Paste it into the box above, or pick an example from the dropdown to see the shape of it.
  3. Click Convert. Switch tabs to see JavaScript, Node.js, or Python output.
  4. Click copy on the code block and drop it straight into your script or test file.

What breaks

  • This is a hand-written parser covering the flags people actually use most: -X, -H, -d/--data/--data-raw/--data-binary/--data-urlencode, -F, -u, -b, -G, -A, --url. It does not implement curl's full Bash/argument grammar the way curl itself or a tree-sitter-based parser does.
  • Shell features inside the command — variable expansion ($VAR), command substitution ($(...)), globs, or chained commands (&&, ;, pipes) — are not evaluated. Paste the literal, already-expanded command.
  • Unrecognized flags (like -v, -s, -i, --http2) are silently skipped rather than causing an error, so the output may omit behavior those flags controlled.
  • File uploads via -F "field=@path" are flagged in the output as a comment, not read from disk — you supply the actual file in your own code (there's no filesystem access in a browser tab).
  • JSON body detection is best-effort: if -d's payload parses as valid JSON it's treated as a JSON body; otherwise it's passed through as a raw string.
Free-tier claim: none applies — this tool makes zero network requests and runs entirely in your browser's JavaScript engine, so there is no rate limit to hit. Evidence the underlying problem is real: the open-source curlconverter npm package (verified npm registry page, ~39,700 weekly downloads at time of writing) exists specifically to solve this.
