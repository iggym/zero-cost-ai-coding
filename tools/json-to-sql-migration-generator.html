JSON to SQL Migration Generator

Infers relational SQL schemas and generates safe, batch `INSERT INTO` DDL migrations from raw JSON payloads entirely client-side, capped only by your browser's local memory performance.

What it replaces: TablePlus Pro ($89 perpetual) or paid schema conversion tools.
How to use: Paste a JSON object or array of objects, set table configuration, and instantly copy the generated DDL statement.
What breaks: Extremely large files (>50MB) may lock browser execution main threads during schema parsing.
