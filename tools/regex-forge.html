How to use

  1. Get a Gemini API key — aistudio.google.com/apikey, sign in with Google, click "Create API key". No card.
  2. Paste your key above. It persists in localStorage — come back anytime.
  3. Describe the pattern in plain English. Be specific: "US phone numbers with optional area code parentheses" works better than "phone numbers".
  4. Pick a flavor — this changes how the pattern is formatted for copying (JS literal, Python raw string, etc.). The regex itself is the same.
  5. Click Generate, then test it in the live tester below the output.

What breaks

  • Rate limit: 15 req/min, 1,500/day on Gemini free tier. Hit it → wait a minute.
  • LLM regexes aren't perfect: Always test the output. The pattern may match more or less than you intended. The live tester catches most issues.
  • Flavor limits: The tester runs JavaScript's RegExp engine. PCRE-specific features (lookbehind before ES2018, atomic groups, recursive patterns) won't test correctly here even if the pattern is valid in Python/PCRE.
  • Vague descriptions: "match emails" gives you a generic pattern. "match RFC-5322 emails" gives you a different one. Specificity matters.
