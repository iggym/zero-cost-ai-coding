How to use

  1. Get a free API key at aistudio.google.com/apikey (Google account, no card). Paste it below — it's held in sessionStorage and is gone when the tab closes. It's sent only to Google's API, via the x-goog-api-key header, never in a URL.
  2. Paste your function(s). Language auto-detects; pick a framework if the default doesn't fit. Toggle edge-case coverage.
  3. Hit Generate tests. Fix the import path at the top of the generated file (it points at ./your-module / your_module), then run: npx jest, npx vitest run, or pytest.

What breaks

  • Rate caps. Hit 429 RESOURCE_EXHAUSTED and you've passed the free tier's RPM or RPD limit: RPM clears in ~a minute, RPD resets at midnight Pacific. Free-tier quotas change without notice — check aistudio.google.com/rate-limit.
  • Your code leaves the browser. The paste is POSTed to Google's Gemini API. Google's free tier may use submitted data to improve its products — don't paste proprietary code you can't share. This is the trade-off for a model far stronger than anything that runs in a tab.
  • The key. sessionStorage only; it dies with the tab. If you reload, re-enter it. The page never logs it and never includes it in exported JSON.
  • Tests need a review pass. The model is good, not infallible. Fix the import path (./your-module / your_module), run the suite, and correct any assertion the model got wrong — you're getting a first draft, not a guarantee.
  • Sandboxed previews. If this page is shown in a sandboxed iframe preview or opened from file:// with restrictions, the API call can be blocked — open the HTML in a normal browser tab.
