How to Use It

  1. Paste your OpenAPI 3.0 or 3.1 schema (JSON format) into the left editor.
  2. The tool parses component schemas, resolves local references ($ref), and outputs strong TypeScript types and Zod schemas in real time.
  3. Click Copy Code and drop the output directly into your TypeScript project or backend handler.

What Breaks / Honest Limits

  1. External network-hosted $ref URIs (e.g., https://example.com/schema.json) are skipped for security and CORS reliability; only internal references (#/components/schemas/...) are fully expanded.
  2. Deeply recursive schemas will generate nested Zod types up to the call stack depth, but extremely cyclic graphs should be handled with explicit Zod lazy wrappers.
