CI Log Triage

Extracts the root cause from massive 10,000-line CI/CD logs by finding the failure context and summarizing it with an LLM, using OpenRouter's free tier (50 requests/day on free models without adding credits).

What it replaces

BuildPulse charges $99/month for CI observability and test analytics, and Datadog CI Visibility is a paid per-committer add-on to their enterprise platform.

How to use it

  1. Get a free OpenRouter API key at openrouter.ai/keys (no credit card required).
  2. Paste your key into the input below (stored only in your browser's localStorage).
  3. Paste your GitHub Actions, GitLab CI, or Jenkins log into the text area.
  4. Click "Triage Log". The tool extracts the failure block client-side and asks the LLM to summarize it.

What breaks

The free tier limit is 50 requests per day and 20 requests per minute. If you hit the limit, you'll get a 429 rate limit error. Also, if the log doesn't contain standard failure keywords (like FAIL, Error:, ##[error]), the heuristic extractor might grab the wrong context.

The Harness Prompt

You are an expert DevOps engineer and LLM architect. We are building a CI/CD log triage tool.
The core problem is context window limits and cost: CI logs are often 10,000+ lines, but the actual failure is usually confined to a single stack trace or test output block near the end of the log.

Your task is to manage context for this specific problem shape using a "heuristic pre-filtering" pattern:
1. Do not send the raw log to the LLM.
2. Write a client-side function that scans the log from bottom-to-top looking for terminal failure markers (e.g., `##[error]`, `Traceback`, `FAIL`, `panic:`, `Exception:`).
3. Once the last terminal marker is found, extract a sliding window of context (e.g., 30 lines before the marker, 10 lines after) to capture the setup and the immediate fallout.
4. Pass ONLY this extracted context window to the LLM for summarization.
5. If no markers are found, fallback to sending the last 150 lines of the log to catch generic exit-code failures.

Maintain this pre-filtering logic strictly on the client side to minimize token usage and avoid hitting API rate limits on free tiers.

// OpenRouter uses the standard OpenAI-compatible chat completions format.
// To force a structured JSON response for log triage, use the `tools` and `tool_choice` parameters.
// Endpoint: POST https://openrouter.ai/api/v1/chat/completions

const response = await fetch("https://openrouter.ai/api/v1/chat/completions", {
  method: "POST",
  headers: {
    "Authorization": `Bearer ${OPENROUTER_API_KEY}`,
    "Content-Type": "application/json",
    "HTTP-Referer": "https://iggym.github.io/zero-cost-ai-coding/",
    "X-Title": "CI Log Triage"
  },
  body: JSON.stringify({
    "model": "meta-llama/llama-3.3-70b-instruct:free",
    "messages": [
      {
        "role": "system",
        "content": "You are a senior Dev engineer. Analyze the provided CI/CD log context and identify the exact root cause of the failure."
      },
      {
        "role": "user",
        "content": `Here is the relevant excerpt from a failing CI log:\n\n${extractedLogContext}`
      }
    ],
    "tools": [
      {
        "type": "function",
        "function": {
          "name": "extract_root_cause",
          "description": "Extracts the root cause, failing command, and fix suggestion from the CI log.",
          "parameters": {
            "type": "object",
            "properties": {
              "root_cause": {
                "type": "string",
                "description": "The exact technical reason the build failed (e.g., missing dependency, syntax error, network timeout)."
              },
              "failing_command": {
                "type": "string",
                "description": "The specific command, script, or test that triggered the failure."
              },
              "fix_suggestion": {
                "type": "string",
                "description": "Actionable steps to fix the issue."
              }
            },
            "required": ["root_cause", "failing_command", "fix_suggestion"]
          }
        }
      }
    ],
    "tool_choice": {
      "type": "function",
      "function": {
        "name": "extract_root_cause"
      }
    }
  })
});
