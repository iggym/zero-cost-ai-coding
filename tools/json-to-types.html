How to use

  1. Paste a JSON API response (or any JSON) into the input box
  2. Set the root type name if you don't want "Root"
  3. Switch tabs for TypeScript interfaces, Zod schemas, or Pydantic models
  4. Click Copy and paste into your codebase
What breaks: Very deeply nested JSON (>50 levels) may hit recursion limits. JSON can't distinguish integers from floats — 1.0 parses as 1, so you'll get int/number where you might mean float. Null values infer as null type, not optional — adjust manually if null means "missing".
