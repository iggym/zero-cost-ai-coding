Diff to Commit Message

Paste a staged git diff, get a conventional commit message back — generated by a small language model that downloads once and then runs entirely in your browser tab, so there's no per-request limit to hit.

Free tier: none — it's your device, not a quota. One-time ~300MB model download, cached after that.

How to use it / what breaks

How to use it: paste a diff (or use the pre-filled example), pick a style, click "Load model & generate." The first click downloads the model — that's the slow part. Every generation after that reuses the cached model and is much faster.

  • Needs a browser with WebGPU (recent Chrome, Edge, or Firefox with the flag on) for reasonable speed. Without it, this falls back to CPU/WebAssembly, which still works but can take 20–60+ seconds per message on a laptop.
  • Runs a 0.5B-parameter model (Qwen2.5-0.5B-Instruct), not a frontier model — it's genuinely free, not genuinely as good as a paid cloud model. Expect it to need a quick human edit on nontrivial diffs.
  • Very large diffs get truncated (first ~6,000 characters) before being sent to the model, so the message may miss context buried deep in a huge diff.
  • Nothing you paste leaves your device — there's no server here to send it to.
  • If the model fails to load (unsupported browser, blocked download, out of memory), you'll see the error in the status line above the button, not a silent failure.
