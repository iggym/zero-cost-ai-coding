What breaks: This tool only knows about a fixed set of well-known security headers (HSTS, CSP, X-Frame-Options, nosniff, Referrer-Policy, Permissions-Policy, COOP/CORP/COEP). It does not detect unknown or custom headers, and it does not validate that your CSP actually blocks anything useful — a syntactically present Content-Security-Policy counts as a pass even if it's default-src *. For real-world CSP evaluation, use Google's CSP Evaluator.
