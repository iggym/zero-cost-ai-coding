Commit Forge

Generate conventional commit messages from your git diff using Google Gemini's free API. Paste a diff, get a commit message you can actually use.

Replaces: GitHub Copilot commit generation ($10/mo), aicommits (requires paid OpenAI key)

Free: 1,500 requests/day — no card needed
Gemini API Key
Get a free key at aistudio.google.com/apikey — no credit card required. Your key is stored in your browser's localStorage only and is never sent anywhere except Google's API.
Git Diff

How to use

  1. Get a Gemini API key — go to aistudio.google.com/apikey, sign in with Google, click "Create API key". No card.
  2. Paste your key in the field above. It saves to localStorage — you won't need to re-enter it.
  3. Stage your changes and run git diff --staged (or git diff for unstaged).
  4. Paste the diff into the text area, click Generate.
  5. Copy the commit message and run git commit -m "..." or use your editor.

What breaks

  • Rate limit: 15 requests/minute, 1,500/day on Gemini free tier. If you hit it, wait a minute or a day.
  • Huge diffs: Gemini 2.0 Flash has a 1M token context — extremely large diffs may fail or get truncated.
  • API changes: If Google changes the free tier or model name, this tool breaks until updated.
  • Network: This calls Google's API directly from your browser. If you're behind a restrictive proxy, it may fail.
