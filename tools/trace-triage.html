Parameterized multi-model prompt pack.

Templates teach the single-file visual-tool pattern. Replace every {{variable}}.

How to use this

  1. For chatbots: select the provider tab, copy the prompt, paste it into your chosen model, replace every {{variable}}, then send.
  2. For code: use the Code / API tab as a JSON payload. Replace {{variables}} programmatically and attach your own API key on the server—not in a public static page.
  3. Every template is parameterized. The small filled example is illustrative; do not hardcode it into your own tool.
