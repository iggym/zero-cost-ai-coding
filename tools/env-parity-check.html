How to use

  1. Paste a source environment in BASE and the deploy target in TARGET.
  2. Press Compare files. Comments, blank lines, optional export, and quoted values are handled.
  3. Add missing keys to the target through your host’s secret/environment UI; use the JSON export only for a key-name audit.

What breaks

This is a text comparison, not a dotenv runtime. It does not resolve variable expansion or tell whether a secret is valid. A “changed” key means the two parsed values differ; it intentionally does not display either value.

Free limit: browser-native processing; no service account or provider quota applies. Large files are bounded by the browser/device.
