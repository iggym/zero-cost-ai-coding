What breaks

    
    
      
  • Empty arrays — can't infer element type, falls back to any / interface{} / Value.
    • 
      
  • null values — marked as optional, but the concrete type is unknown (was it a string? an object?). You'll need to fill in the actual type.
    • 
      
  • Mixed-type arrays like [1, "two"] — only the first element's type is used.
    • 
      
  • Very large JSON — no hard limit, but browser memory is the constraint. Works fine up to a few MB.
    • 
      
  • Non-JSON input — shows a parse error at the top of the input panel.
