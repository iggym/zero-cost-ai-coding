For chatbots: Pick your model tab, copy the system + user prompt, paste into ChatGPT / Claude / Gemini. Replace all {{variables}} with your problem details. Send.

For code/API: Use the Code / API tab — each block is a ready JSON payload for that provider's API. Replace {{variables}} programmatically before calling the endpoint.

For local/open-weight: Use the Open-Weight tab. Plain system/user template with JSON schema — works with vLLM, Ollama, or any endpoint serving Llama 3.1 / Mistral / Qwen2. No tool wrappers needed.
