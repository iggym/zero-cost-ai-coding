    How to Use & Edge Cases

    How to use: Type or paste any standard 5-part cron syntax (`min hour day-of-month month day-of-week`). Select your production server's timezone to preview execution dates without manually computing UTC offsets.

    What breaks: Non-standard 6 or 7-part cron syntaxes (including seconds or years) and complex macro extensions (like `@reboot`) are filtered out. Standard 5-field syntax is enforced.

    Verified via MDN Web Docs (Intl API Docs). Zero server calls.
