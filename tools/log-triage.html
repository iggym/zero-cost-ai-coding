Log Triage

Paste a messy server log, get an instant triage report (unique errors, root cause hypothesis, suggested fixes) using your free Google Gemini API key. Free limit: 1,500 requests/day.

What it replaces: No direct paid equivalent found for instant paste-and-triage. Log management platforms like Datadog offer automated triage but require full agent integration and start at paid tiers.

How to use it: Get a free API key from Google AI Studio (no card required). Paste your log below. Enter your key and click Run Triage. Your key is stored only in your browser's memory for this request.

What breaks: You are limited to 15 requests/minute and 1,500 requests/day on the free tier. If your log is massive (over ~1M tokens), the request will fail. The API key is never sent to any server except Google's.

Build This Yourself

This tool uses function calling to force the LLM to return a strict, parseable JSON structure rather than prose. Here are the prompts to build a similar tool.

1. Harness Prompt

You are an expert DevOps assistant. Your task is to triage server logs and error dumps. Context management strategy: Server logs are often massive and repetitive. If the log exceeds the context window, do not summarize blindly. Instead, extract only lines matching severity keywords (ERROR, FATAL, Exception, Traceback). If the extracted slice is still too large, chunk by timestamp or file block, extract unique error signatures from each chunk, and maintain a running count of occurrences. Discard raw INFO/DEBUG lines. Keep only the deduplicated error signatures, their counts, and a representative stack trace for the root cause analysis.

2. Tool-Calling Prompt (Gemini v1beta API)

{
  "tools": [
    {
      "functionDeclarations": [
        {
          "name": "submit_triage_report",
          "description": "Submits the structured triage report for the given logs.",
          "parameters": {
            "type": "OBJECT",
            "properties": {
              "unique_errors": {
                "type": "ARRAY",
                "items": {
                  "type": "OBJECT",
                  "properties": {
                    "signature": { "type": "STRING", "description": "Short name of the error" },
                    "count": { "type": "INTEGER", "description": "Number of occurrences" },
                    "example_line": { "type": "STRING", "description": "One representative line" }
                  }
                }
              },
              "root_cause_hypothesis": { "type": "STRING" },
              "suggested_fixes": { "type": "ARRAY", "items": { "type": "STRING" } }
            }
          }
        }
      ]
    }
  ],
  "toolConfig": {
    "functionCallingConfig": {
      "mode": "ANY"
    }
  }
}
