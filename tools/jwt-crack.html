How to use

  1. Paste your JWT in the text area. It decodes instantly — no button to click.
  2. Check the header for the algorithm and token type.
  3. Check the payload for claims — decoded, formatted, syntax-highlighted.
  4. Read the analysis — expiration status, security flags, claim explanations.
  5. Copy the decoded header or payload as clean JSON.

What breaks

  • JWE tokens (5 parts, encrypted payload) can't be decoded here — only JWS tokens (3 parts) are supported. You'll see an error if you paste one.
  • Non-JSON payloads — some exotic JWTs use non-JSON payloads. You'll get a parse error.
  • Clock skew — expiration checks use your browser's clock. If your clock is off, the "expired" status will be wrong.
  • No signature verification — this decodes and analyzes but does NOT verify the signature. Anyone can create a token with any claims. Never trust a decoded token without verifying its signature server-side.
