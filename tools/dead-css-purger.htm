How to Use

  1. Paste your source template code (HTML, Blade, JSX) in Panel 1.
  2. Paste your main CSS file or compiled utility sheet in Panel 2.
  3. Click Run Purge Engine. The client-side scanner tokenizes class names and discards rules not explicitly present in the template.
  4. For dynamic template strings or conditionally concatenated classes, optionally provide your own Gemini API key to trigger an LLM scan of runtime edge cases.

What Breaks (Honest Limits)

  • Pure Client Mode: Heavily mutated class names dynamically constructed via string concatenation (e.g. `text-${color}-500`) cannot be detected by static regex scanning alone. Use the Gemini BYOK mode to resolve these safely.
  • Gemini Free Rate Limit: Standard free API keys are capped at 15 RPM (Requests Per Minute). Exceeding this triggers a standard HTTP 429 backoff error.
