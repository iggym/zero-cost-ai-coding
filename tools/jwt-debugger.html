    How to use this

    1. Paste a JWT token in the input field
    2. Click "Decode JWT" to see the header, payload, and signature
    3. Review the decoded header (algorithm, type) and payload (claims)
    4. Check the claims validation table for exp, nbf, iat status
    5. Optionally enter a secret key to verify HMAC signatures
    6. Review any warnings about missing or suspicious claims
