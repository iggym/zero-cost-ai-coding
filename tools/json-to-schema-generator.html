What it replaces

This replaces freemium web tools like jsonschema.net (which gates batch processing and CLI features behind a $10/mo Pro tier) or manual schema writing. It runs entirely in your browser, so your data never leaves your machine.

How to use it

1. Paste your JSON into the left textarea.
2. The schema generates instantly on the right.
3. Toggle "Strict Mode" if you need additionalProperties: false (required for OpenAI structured outputs).
4. Copy the schema to your clipboard or download it as a .json file.

What breaks

Extremely large JSON files (>5MB) may cause the browser tab to freeze momentarily since processing happens synchronously on the main thread. Mixed-type arrays will infer the schema from the first element in the array.
