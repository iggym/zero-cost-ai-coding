What it replaces

Sqlizer.io's Individual plan ($39/month), which limits free use to 500 rows and charges for bulk processing.

How to use it

Paste a JSON array of objects. Name your table. The right pane generates schema-aware SQL. Copy or download the .sql file and run it in SQLite, Postgres, or MySQL.

What breaks

Nested objects and arrays are stringified into TEXT columns. Very large inputs (>5MB) may freeze the tab. Mixed-type arrays use the first element's type.

Free-tier verification: This tool runs entirely in your browser with no external API calls. Standard SQL syntax verified against sqlite.org/lang.html.
