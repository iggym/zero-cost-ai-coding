What it replaces

Mockaroo paid plans: $60/year (100k rows) to $500/year (10M rows). Free tier limited to 1,000 rows per file.

How to use it

  1. Paste a sample JSON object (an API response shape, database record, etc.)
  2. Click "Analyze Schema" to see detected field types and faker methods
  3. Adjust faker methods per field if needed (optional)
  4. Set number of rows (up to 10,000) and output format
  5. Click "Generate" to create realistic test data
  6. Copy to clipboard or download as a file
