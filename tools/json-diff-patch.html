What breaks

    
    
      
  • Very large JSON (tens of MB) may freeze the tab — the diff is O(n) in document size but runs synchronously on the main thread.
    • 
      
  • Array diffing is positional (index-based), not by identity. If you reorder array elements without changing their contents, it won't detect "moved" — it'll report a bunch of replacements. RFC 6902 doesn't have a native "move" op for arbitrary reorders either, so this matches the spec.
    • 
      
  • Patch application: not implemented here (that's a different tool). Use the patch with any RFC 6902 library — Python's jsonpatch, JS's fast-json-patch, Go's json-patch, etc.
