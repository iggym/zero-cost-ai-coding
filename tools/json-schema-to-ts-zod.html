What breaks

      
This generator processes standard JSON Schema primitives (objects, arrays, strings, numbers, booleans, enums, and required properties). Ultra-complex draft features like recursive $ref resolving to external network URIs or complex allOf/oneOf conditional logic require full AST compilers, but standard local definitions parse seamlessly.
