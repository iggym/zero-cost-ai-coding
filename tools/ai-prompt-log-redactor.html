Build This Yourself (Prompt Pack)

Deploy this pattern using parameterized prompts for any target LLM provider.

  1. Select a target LLM tab above.
  2. Click Copy Prompt to grab the parameterized template.
  3. Replace double-curly variables (e.g. {{PROBLEM}}, {{INPUT_EXAMPLE}}) in your automation workflow.
Title: For OpenAI GPT-4o — Sensitive Log Redactor
Parameters: temperature: 0.2, top_p: 0.95, max_tokens: 4096

System Prompt:
You are an expert log redactor for {{AUDIENCE}}. Sanitize the input according to {{SOLUTION_MODE}} specifications as of {{DATE}}. Replace sensitive tokens like API keys, secrets, and PII using {{FREE_SERVICE}} pattern matching rules.

User Prompt:
Sanitize the following input payload and return a clean string plus a JSON list of identified secrets.
Input: {{INPUT_EXAMPLE}}

Tools Schema (Chat Completions):
{
  "type": "function",
  "function": {
    "name": "redact_sensitive_data",
    "description": "Redacts detected credentials and PII",
    "parameters": {
      "type": "object",
      "properties": {
        "sanitized_text": { "type": "string" },
        "detected_entities": {
          "type": "array",
          "items": {
            "type": "object",
            "properties": {
              "type": { "type": "string" },
              "value": { "type": "string" }
            }
          }
        }
      },
      "required": ["sanitized_text", "detected_entities"]
    }
  }
}
