curl-to-code

Curl-to-Code Converter

Paste a curl command and get idiomatic code in Python requests, JavaScript fetch, Node.js, Go, PHP, Rust, and more. Handles common flags (-X, -H, -d, -u, -b, -F, -L). Runs entirely in your browser — your curl command never leaves your machine.

limit: ∞ — pure client-side parsing, no network calls

What it replaces

Asking "how do I convert this curl to python" on Stack Overflow, or manually translating -H, -d, and -u flags every time you find an API example in docs.

How to use

Paste any curl command (the curl word itself is optional). Click Convert. Switch languages with the tabs. Copy the result into your code.

Try: simple GET POST JSON basic auth form data custom headers

What breaks

This handles the most common curl flags: -X, -H/--header, -d/--data/--data-raw, -u/--user (basic auth), -b/--cookie, -F/--form, -L/--location, -k/--insecure, -e/--referer, -A/--user-agent. It does not handle: shell variable expansion ($VAR), backtick substitution, complex shell pipes, --compressed, OAuth token flows, or advanced curl features like --write-out. For complex cases, use curlconverter.com.
